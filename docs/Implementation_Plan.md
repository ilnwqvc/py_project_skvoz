## Схема данных

raw:
JSON ответ API без изменений

normalized:
табличный слой после очистки и приведения типов
одна строка = одно наблюдение (час)

mart:
агрегированная витрина по дням
содержит KPI (средняя температура, осадки, ветер, дождливые часы)
используется для анализа и визуализации

## Почему слои разделены

Разделение нужно для:
- raw — хранит оригинальные данные (можно перепроверить)
- normalized — очищенные данные
- mart — быстрый анализ и KPI

Если делать всё в одном файле:
- сложно отлаживать
- нельзя переиспользовать данные
- выше риск ошибок
