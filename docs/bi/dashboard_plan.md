# План дашборда

Источник:
- таблица `mart_variant_06`

Название можно сделать простое, например:
- `Погода по витрине mart`

## График 1

Тип:
- line chart

Что показывать:
- как менялась средняя температура по дням

Поля:
- X: `date`
- Y: `T_mean`

Название:
- `Средняя температура по дням`

## График 2

Тип:
- bar chart

Что показывать:
- в какие дни осадков было больше всего

Поля:
- category: `date`
- value: `P_sum`

Что еще настроить:
- сортировка по `P_sum` по убыванию
- ограничение top 7

Название:
- `Топ-7 дней по осадкам`

## График 3

Тип:
- table или bar chart

Что показывать:
- `rainy_hours` и `wind_max` по дням

Если через таблицу:
- колонки `date`, `rainy_hours`, `wind_max`, `P_sum`

Если через bar chart:
- можно взять только `rainy_hours`

Название:
- `Дождливые часы и ветер`

## Что важно

- графики должны строиться именно по таблице `mart_variant_06`
- источник в Metabase должен быть Postgres, не CSV
