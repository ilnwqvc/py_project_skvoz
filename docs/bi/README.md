# BI

В этой папке лежат материалы по BI-части проекта.

Что здесь должно быть:
- скрин дашборда целиком
- скрин одного-двух графиков

Источник данных:
- таблица `mart_variant_06` в Postgres

Что показывается на дашборде:
- динамика по времени
- ranking по осадкам
- еще один сводный график или таблица

Важно:
- графики строятся не из CSV
- Metabase подключается к Postgres
